# Phone checklist

These could not be tested on a real device while building. Tick them off on an iPhone (Safari) and an Android phone (Chrome) before relying on them.

## Install and offline
- [ ] iPhone: Share > Add to Home Screen. The icon, name "NiHi" and white status bar look right.
- [ ] Android: the install prompt appears, and the installed app opens full screen.
- [ ] Turn on airplane mode, open the app: you see the offline page or cached screens, not a browser error.
- [ ] Add an expense offline, go back online: it is added once (not twice) and a toast confirms it.

## Layout
- [ ] No horizontal scroll on any page; nothing hidden behind the bottom tab bar or the home indicator.
- [ ] Inputs do not zoom the page when focused (font size is 16px).
- [ ] The "My account" dock at the top and the quick-add fan-out button are comfortable to tap.
- [ ] Date picker opens on tap and its popup fits the screen.

## Scanning
- [ ] Pick a screenshot from the photo library: text is read, the form is filled, nothing is saved until you confirm.
- [ ] Image preview opens and can be swiped/closed.

## Wallet
- [ ] Drag-and-drop account ordering works with touch and the order stays after refresh.
- [ ] Swipe-to-delete / bulk select on transactions works without scrolling the page by accident.

## Language
- [ ] Switch to Sinhala: letters render (no empty boxes), nothing is cut off. Have a Sinhala speaker review the wording.
